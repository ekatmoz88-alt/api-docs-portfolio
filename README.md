# API Documentation Portfolio — Legacy Workspace

> **Status:** legacy documentation workspace for the real Orders API project. This repository is not the primary API portfolio and should not be confused with the expanded [API Documentation Portfolio V2](https://github.com/ekatmoz88-alt/api-docs-portfolio-v2).

## Purpose

This repository is an early, minimal API documentation workspace. Its current contents are limited to the repository README and the `openapi/` directory. It does not contain the complete set of developer guides, API case studies, quality checks or bilingual publication available in V2.

## Recommended entry point

Use [API Documentation Portfolio V2](https://github.com/ekatmoz88-alt/api-docs-portfolio-v2) as the canonical API documentation portfolio. It contains REST/OpenAPI 3.1 materials, legacy SOAP/WSDL case studies, documentation QA and EN/RU materials.

- [Published V2 documentation](https://ekatmoz88-alt.github.io/api-docs-portfolio-v2/)
- [OpenAPI reference](https://ekatmoz88-alt.github.io/api-docs-portfolio-v2/openapi/)

## Scope and evidence

This repository preserves early OpenAPI documentation artefacts for the real Orders API project. The deployed API implementation and expanded documentation are maintained in [API Documentation Portfolio V2](https://github.com/ekatmoz88-alt/api-docs-portfolio-v2).
