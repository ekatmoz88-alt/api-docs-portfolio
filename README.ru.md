# Портфолио API-документации — ранняя рабочая версия

[English](README.md) | [Русский](README.ru.md)

> **Статус:** ранняя рабочая область документации реального проекта Orders API. Это не основное API-портфолио; его не следует путать с расширенным [API Documentation Portfolio V2](https://github.com/ekatmoz88-alt/api-docs-portfolio-v2).

## Назначение

Репозиторий представляет собой раннюю минимальную рабочую область для документации API. Сейчас его содержимое ограничено README и каталогом `openapi/`. Здесь нет полного набора руководств разработчика, кейсов API, автоматических проверок качества и двуязычной публикации, которые представлены в V2.

## Основная версия портфолио

Каноническая версия API-портфолио — [API Documentation Portfolio V2](https://github.com/ekatmoz88-alt/api-docs-portfolio-v2). В ней собраны материалы REST/OpenAPI 3.1, кейсы legacy SOAP/WSDL, проверки качества документации и материалы EN/RU.

- [Опубликованная документация V2](https://ekatmoz88-alt.github.io/api-docs-portfolio-v2/)
- [Справочник OpenAPI](https://ekatmoz88-alt.github.io/api-docs-portfolio-v2/openapi/)

## Границы и доказательность

Репозиторий сохраняет ранние артефакты OpenAPI-документации реального проекта Orders API. Развёрнутая реализация API и расширенный комплект документации находятся в [API Documentation Portfolio V2](https://github.com/ekatmoz88-alt/api-docs-portfolio-v2).
